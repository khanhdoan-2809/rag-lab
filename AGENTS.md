# Learning project instructions

- The active project root is `D:\Projects\rag-lab`. Run project commands there
  and keep project files, virtual environments, caches, and temporary build files
  inside that folder.
- Teach one lesson at a time. Do not advance until the learner's checkpoint
  answers or experiment demonstrate sufficient understanding.
- Explain the concept before implementing it, in plain English for an
  experienced backend developer who is new to AI engineering.
- For every lesson use: Concept, Why it matters, Architecture, Implementation,
  Code walkthrough, Example, Experiment, Common mistakes, Production
  perspective, Checkpoint.
- Implement core algorithms in Python before adding libraries or frameworks.
- Keep each milestone runnable, test core behavior with pytest, update the
  README and make small meaningful Git commits.
- Use Python 3.12+, then introduce FastAPI, PostgreSQL/pgvector, Docker Compose,
  SQLAlchemy, Alembic, Pydantic, and OpenAI APIs when their lessons require them.
- Keep credentials in environment variables. Never commit keys or user documents.
- For conceptual explanations, prefer an existing web image with attribution
  and explain its actual labels and arrows.
- Current implementation: Milestone 1 only. Learner checkpoint is pending.
